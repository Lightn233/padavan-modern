# 界面回归

这是 Linux 上的 DOM、交互及进度状态机测试，使用固定模拟数据，不连接真实路由器。

```sh
cd tests/webui-modern
npm ci
python3 run.py
```

需要 Python 3、Node.js 24.15+（或 26+）和 Git。测试只在临时目录展开网页组件及其基线，不复制完整源码。结果默认写入 `/tmp/padavan-webui-results`，测试临时目录退出时删除，报告保留。8767 端口必须空闲。

覆盖表单字段、页面初始化、WAN 类型联动、模式切换取消与确认、AGH 备份按钮、同名节点独立选择、图表刷新/范围/平移、帮助提示、网络断开及 DFS 等待状态。

模拟无线能力和地址均为测试数据，不是任何地区的信道政策或真实设备状态。真实浏览器布局、触摸、焦点、HTTP 认证、保存后服务行为、无线收发和长期稳定性仍需分别验收。测试通过不表示可以直接刷机。
