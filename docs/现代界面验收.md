## 2026-10-31 验收后状态接口修复

用户已确认预览界面验收通过，并授权编译、部署。此记录属于用户视觉验收，不代表浏览器自动控制已经恢复。

打包前发现并修复了状态接口格式差异：原 `json_system_status` 钩子输出 JavaScript 对象字面量，包含无引号键名与十六进制计数器，不符合新版轮询需要的标准 JSON。原模拟服务使用 `json.dumps`，没有覆盖该缺陷。现将后端键名加引号、计数器按十进制输出，并初始化采样结构体；嵌入 `state.js` 的原用法仍兼容。

新增测试直接抽取实际 C 钩子进行编译，不借助模拟服务器生成响应：Ubuntu 原生复现旧格式解析失败，修复后的实际 `/proc` 数据及读取失败场景通过（共 3 项）；MIPS 静态编译和 QEMU 的对应两项测试通过。该测试已加入仓库统一回归入口。部署后再次请求真实 `/system_status.json`，标准 JSON 解析、CPU 计数器递增与内存加总均通过。
