# RM2100 U9D11：SCS 状态复位与流量图短时段修复

2026-11-02，已通过正常升级入口实装。Flash、实际模块、网页文件、用户配置、官方 AdGuard Home、双栈 DNS 与 HTTPS 均完成核对。

## 修复

- MT7603 的 SCS 流量占比使用宽整数、一次计数快照及空闲保护，避免空闲除零和百分比计算溢出；该项在 U9D9 已实装。
- SCS 关闭时同步复位两个软件灵敏度状态，使重新开启后的调节与已经恢复的硬件一致。对生产函数执行 9 项原生 ASan/UBSan 与 MIPS 开关序列回归，并在正式驱动上确认关闭后两项均为 -102、重新开启正常。
- 实时图表最短范围为 2 秒；拖动中固定时间基准，旧样本滚出时约束选区，日期与时长按同一规则显示。
- 很短的窗口不再因为落在两个采样点之间而空白：保留相邻点之间的线段，单个真实采样点画为圆点。没有新增流量采样或修改统计值。15 项范围/稀疏采样回归通过，浏览器曲线和单点实际显示通过。

## 2.4 GHz 实测与配置选择

手机到有线电脑的受限局域网传输：本次正式 U9D11 下行 137.33 Mbps、上行 127.39 Mbps；同时采集的网关延迟平均为 8.44 / 24.28 ms，丢包为 0.0% / 0.0%。下载最多 12 秒，上行最多 128 MiB/12 秒；上行先完成时，延迟窗口会包含部分空闲时间。这是短时、单位置结果，不是全天或全房屋保证。

先后比较 1/6/11 信道、20 MHz/20-40 共存、APSD、LDPC、TxBurst、A-MSDU 和 SCS 开关。替代设置未表现出稳定的综合优势；原 11 信道、20/40 模式同样出现过约 83–139 Mbps 的下行波动。因此最终按测量选择原组合，不能把参数未变误解成没有测试，也不能把本次代码可靠性修复当作全部 RF 性能问题根治。所有临时设置和恢复任务均已清理。
