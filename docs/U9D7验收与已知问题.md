# RM2100 U9D7：已实装修复与验收范围

2026-11-02。本分支保存已编译、实装并完成短时验收的源码，基于先前 U9D5 阶段分支继续更新。

## 修复内容

- 流量统计按终端视角区分上传和下载：LAN、无线和交换机端口的方向与 WAN 不同。实时图、当前数值和历史累计统一映射；接口重建、计数回退和轮询中断重新采样，避免伪造峰值。路由器真实上传／下载数据已验证，U9D7 实际 HTTP 函数与该验收版本一致。
- 访客限速增加后端状态批次和请求关联，避免旧成功或旧失败结束当前保存；关闭访客时及时移除网桥成员，MT7615 主网和访客使用一致的聚合间隔。
- 后台进程和设备状态读取、快速设备刷新、长驻页面刷新与资源版本等修复；为 PPP LCP、检测、无线和其他难懂设置补充用途与影响说明。
- AGH 与 Storage 维护使用进程退出后释放的锁；配置原子写入、完整暂存再替换、失败恢复和独立临时包，减少异常退出或并发操作对 DNS 与配置的影响。官方 AdGuard Home v0.107.79 主程序保持原样。
- MT7603 2.4 GHz 升级至社区 4.1.2.1-mao-patch1 适配版；MT7603、MT7615 关闭网络接口时补齐硬件 NAT 注销。
- MT7615 构建 40／80／160 MHz 自动信道候选组时补齐相邻索引边界检查，保持评分和 DFS 约束。

本机配置不启用 SmartDNS、Adbyby、Singbox；先前已确认的共享源码修复不代表这些可选功能在该镜像中启用或完成现机验收。

## 驱动来源和构建身份

MT7603 上游为 [trublemaker/mt7603-4.1.2.1](https://github.com/trublemaker/mt7603-4.1.2.1)，参考提交 `66c456095b928884a0f93615867649ddd57993da`。保留上游许可声明与本树的板级适配。MT7615 仍基于 5.1.0.0，不是换成 MT7603 驱动。

实装镜像 `RM2100-U9D7_4.4.198.9-100.trx`，19601256 字节，SHA256 `99e77996575d0b8c7b62fe257a566ecf81cea256931250efa25fb05feae04c61`。文件名保留项目旧格式，实际内核为 4.4.302-cip115-c2。

源码清单及各文件摘要见 `U9D7-source-manifest.json`。源码按原始字节发布，包括非 UTF-8 驱动文件，不进行有损转码。设备配置、凭据、用户网络记录及原始手机诊断不属于公开源码。

## 已完成验证

1. 既有未改代码沿用原验收，包括真实上传／下载、访客双客户端隔离、限速状态、维护锁、DNS 原子配置和 Storage 回滚等。隔离异常路径测试与现机正常路径验收分别记录，不扩大为全功能故障注入。
2. 新 MT7603 适配版完成目标符号／版本检查、RAM 正常传输与主网／访客双栈检查；最终模块机器码与接受的 RAM 版本一致。正式刷机后再次核对 Flash、模块和启动版本。
3. MT7615 实际候选构建函数通过 9 个正常信道列表用例：原生 ASan／UBSan 与 MIPS 执行均通过；随后完成驱动与全固件构建。
4. 镜像 CRC、49 份实际页面和资源、组件及官方 AGH 核对；正常升级后，有线 DNS UDP／TCP 和 IPv4／IPv6 HTTPS 通过，手机主 2.4 GHz、主 5 GHz、临时访客 5 GHz 双栈 HTTPS 通过。
5. 手动 36／160 MHz 下，手机分别连主网和访客时均能取得两路新鲜扫描记录。测试后恢复 36／160 MHz、访客关闭，配置及回退包保留，临时设置和本轮新建手机网络清理。

## 尚未解决或未覆盖

- 小米 12 / HyperOS 3.0.3.0 在 64／160 MHz 连接一条 5 GHz 网络后，另一条会缺少于系统扫描结果。电脑仍收到两路新鲜广播；根因尚未证明。U9D6 手动 36、40、44、48、52、56、60 均通过双向观察，64 重复失败。固定 36 是已验证工作设置，不能称作根治；升级 2.4 GHz 驱动也不能代表修好此 5 GHz 问题。
- 当前自动选信道仍为厂商忙碌时间算法，未替换为新的优化评分。自动 160 MHz 的默认跳过列表与候选过滤仍需专门验证；手动信道测试不等于自动模式验收。
- 首次未修正的 RAM 驱动替换出现重启，之后修正 NAT 注销并调整替换流程，接受的 RAM 版本和正式固件未再复现。没有崩溃栈证明首次异常精确根因；短时验收不代替长期稳定性。
- 特殊 IPv6 源／目的作用域、运营商 Bootstrap 超时、RSSI 重关联以及部分动态手机界面保留各自验收边界。
