# U9D5 候选：访客开关、状态查询与流量统计

候选仍未整包刷入。较早的后台清理版本完成了完整编译和包内核验；后续新增的设备列表与扫描修复完成了独立编译、临时实机测试，并已合入候选源码，需重新整包构建。不能将旧镜像视为当前分支的成品。

## 改动

- 打包时按 JS/CSS 实际内容生成资源版本，防止升级后浏览器混用旧的开关插件与现代组件。
- 55 个页面共 167 处开关调用直接使用现代组件，删除旧的包装脚本、无引用样式与本地化资源，以及 22 个重复或无引用函数。保留仍被页面使用的依赖与校验。
- AdGuard Home 链接指向官方 GitHub。管理入口通过认证后的只读状态接口刷新当前地址、端口及协议；停止服务或入口不可用时移除失效链接。状态轮询不覆盖未提交的设置，隐藏页面后暂停。
- 内存数据按字段解析，处理缺失、变序和无效数据；CPU 差值算法保持原样。
- 流量统计处理接口代次变化、计数复位、采样中断与条目过期；图表历史长度有界，并校正 LAN/WAN 的上下行方向。
- 修复 Base64 解码的有符号字符索引和管理会话占用时受保护请求分派。
- 设备列表的“刷新”改为只读更新，另设“扫描新设备”。全网扫描使用隐藏回调，留在完整管理界面；扫描期间保留已有行，同名设备按不同 MAC 分开，扫描结束后移除失效行。
- 设备发现每批发送少量 ARP 探测再收包，消除每个空地址串行等待；最后一批收包后才发布完成状态。没有缩短每次收包超时或跳过地址。

`state.js` 从 46,281 字节减少到 27,927 字节。减少网页代码不等于提高无线吞吐，后者没有据此宣称改善。

## 复验方法

在仓库根目录执行。C 测试需要 GCC；JavaScript 测试复用已有 `tests/webui-modern/package-lock.json` 的 jsdom 依赖。

```sh
python3 tests/webui-modern/test-adguardhome-status.py
python3 tests/webui-modern/test-http-dispatch.py
python3 tests/webui-modern/test-metrics-c.py
npm ci --prefix tests/webui-modern
node tests/webui-modern/test-adguardhome-ui.cjs
node tests/webui-modern/test-traffic-counters.cjs
node tests/webui-modern/test-client-refresh.cjs
python3 tests/webui-modern/test-networkmap-scan.py
```

C 测试可传 `--source`、`--results`、`--cc`、`--runner qemu-mipsel`。JavaScript 可设置 `PADAVAN_SOURCE` 与 `PADAVAN_TEST_RESULTS`。测试使用隔离输入，不发送异常请求到路由器，也不写设备配置。
