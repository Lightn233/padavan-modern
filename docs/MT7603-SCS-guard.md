# MT7603 SCS counter arithmetic

SCS uses the receive share of one-second traffic to select a sensitivity path. Snapshot both byte counters once, use wide arithmetic for the share, and let an idle interval reach the existing sensitivity-reset path. Retain all channel, bandwidth, power, sensitivity thresholds and rate adaptation policies.

Validation: the extracted production function passes 15 idle, normal-traffic, counter-bound and sensitivity-path checks on native ASan/UBSan and MIPS. The MT7603 module builds against the RM2100 kernel and all 127 required symbol versions match. The public test runner compiles the current production function; it does not exercise the previous implementation or send traffic to a device.

The arithmetic fix was subsequently packaged and installed in U9D9 and U9D11. U9D11 additionally resets both software sensitivity fields when disabling SCS, keeping them consistent with the restored hardware before the next enable; nine disable/reenable cases pass on native ASan/UBSan and MIPS. Flash readback and the loaded module hash match the packaged image; the official AdGuard Home binary and user network data were retained. See U9D11 acceptance notes for the bounded hardware measurements. This arithmetic correction is not evidence that an RF throughput or latency complaint is resolved. Channel/width comparisons, real client throughput and loaded-latency measurements are still required for a performance claim.
